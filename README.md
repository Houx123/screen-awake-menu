# 熄屏不休眠

一个原生 macOS 菜单栏小工具。点击菜单栏的显示器图标，再选“立即熄屏（主机保持运行）”，只关闭显示器；Mac 依靠系统能耗设置保持唤醒，继续等待远程连接。

## 使用

1. 双击 `熄屏不休眠.app`。
2. 点击菜单栏里的显示器图标。
3. 选择“立即熄屏（主机保持运行）”。

移动鼠标或按任意键即可重新点亮显示器。App 平时不轮询，也不启动额外常驻子进程，只保留一个等待菜单点击的轻量进程。点击熄屏时调用一次 macOS 自带命令，命令完成后立即退出。

## 重新构建

```sh
./build.sh
```

构建产物位于 `build/熄屏不休眠.app`。
